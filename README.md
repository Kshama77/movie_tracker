# MovieTracker 🎬

A beginner-friendly Java console app for keeping track of movies you've watched and your ratings.

## Features
- Add movies by title and release year
- View your movie list
- Rate movies from 1 to 5 stars
- Remove movies from your list
- Input validation for years, ratings, and menu selections

## Concepts practiced
- Classes and objects
- `ArrayList`
- Methods
- Loops and `switch`
- `Scanner` input
- Basic validation and exception handling

## Requirements
- Java JDK 8 or newer

## Run the app
From the project folder, run:


```bash
javac src/MovieTracker.java
java -cp src MovieTracker
```

## Note
Movies are stored in memory while the program is running. The list resets when you exit.
